# Reels Cord

A simple discord bot that has a sole purpose to let you share your brainrotted reels to your discord friends which may lack instagram.

## How to use?
- Drop a link down a channel, and count it done!
- Ping the bot for help
- Do `@Reelscord set #channel` for setting a logging channel for deleted reels
- Do `@Reelscord remove` for removing the currently set logging channel.
- React with ❌ to delete your sent reels
